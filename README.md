# Лабораторная работа №5: База данных роботов и сотрудников

## 📝 Описание проекта
Данный репозиторий содержит SQL-скрипты для проектирования, наполнения и анализа базы данных. 
Согласно заданию, база данных моделирует компанию, в которой за каждым сотрудником закреплен определенный робот. В рамках работы были реализованы расчеты годовых премий на основе квартальных оценок, а также проведена индексация заработных плат и составлен итоговый финансовый отчет по отделам.

## 🛠️ Используемые технологии
*   **СУБД:** PostgreSQL
*   **Инструменты:** pgAdmin 4 / SQL Shell (psql)

## 📂 Структура репозитория
*   **`Создание БД.sql`** — Скрипт создания структуры БД (таблицы `departments`, `robots_employees`, `quarterly_evaluations`) и наполнения её тестовыми данными.
*   **`Запросы Lab5.1.sql`** — Файл со всеми аналитическими запросами из первой части заданий к лабораторной работе:
    *   Запросы из первой части (пункты 6.1–6.8: стаж, фильтрация оценок, расчет коэффициента премии).
*   **`Запросы Lab5.2.sql`** — Файл со всеми аналитическими запросами из второй части заданий к лабораторной работе:
    *   Запросы из второй части (пункты a–g: поиск максимумов, JOIN-запросы, индексация зарплат и генерация итогового отчета для финансового отдела).

## 🚀 Как запустить
Для того чтобы развернуть базу данных и проверить работу запросов, выполните следующие шаги:

1.  Откройте **pgAdmin 4** (или `psql`) и подключитесь к вашему серверу PostgreSQL.
2.  Создайте новую базу данных (например, с именем `robots_lab_db`). Убедитесь, что кодировка установлена в `UTF8`.
3.  Откройте **Query Tool** для созданной базы.
4.  Выполните скрипт из файла **`01_schema_and_data.sql`** (он создаст таблицы и добавит все необходимые записи).
5.  Выполняйте запросы из файлов **`Запросы Lab5.1.sql`** , **`Запросы Lab5.2.sql`** по одному, чтобы увидеть результаты аналитики.
